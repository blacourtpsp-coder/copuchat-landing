# Copuchat · Landing page

Landing de campaña para **Copuchat**, la plataforma donde se conversa con **Latam-GPT**, la primera IA de lenguaje abierta hecha por y para Latinoamérica (liderazgo técnico de CENIA).

Trabajo universitario de marketing — campaña "Una IA con acento propio".

## Ver la página

Publicada con GitHub Pages: **https://blacourtpsp-coder.github.io/copuchat-landing/**

## Contenido

- `index.html` — la landing completa (HTML + CSS + JavaScript, sin dependencias).
- `img/` — fotografías usadas en la página.

## Notas

- Diseño responsive (computador, tablet y celular).
- El formulario y el asistente son demostrativos: no envían ni guardan datos.
- Los textos entre [corchetes] son pendientes por completar (testimonios, fechas de webinars, resultados de benchmarks).
- Fuentes de datos: CENIA y CAF (lanzamiento de Latam-GPT, febrero 2026). ChatGPT y Gemini son marcas de sus respectivos dueños.
